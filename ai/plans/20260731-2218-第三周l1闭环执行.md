## 调研方案

### 研究维度

1. TLA+ CLI 稳定版、Java 要求、配置语法与状态/轨迹导出接口。
2. L1 strict-2PL 的最小可执行状态机、invariant 与状态空间边界。
3. Java 事件到抽象动作的多值映射与 inconclusive 传播。
4. 可审计 canonical trace、自测试和 Week 2 回归适配。
5. PR #95 差分压力和 low instrumentation 性能门槛。

### 一手来源

- [TLA+ Tools 官方仓库](https://github.com/tlaplus/tlaplus)说明 CLI jar、Java 11+ 要求和各工具入口。
- [TLA+ v1.7.4 官方发布](https://github.com/tlaplus/tlaplus/releases/tag/v1.7.4)提供本周固定的稳定发布物。
- [TLC 配置官方 Wiki](https://docs.tlapl.us/using%3Atlc%3Aconfig_file)说明 model values、常量与 symmetry 配置。
- [当前 TLA+ 工具说明](https://github.com/tlaplus/tlaplus/blob/master/general/docs/current-tools.md)说明 TLC 命令行、simulation、dump 和性能参数。
- [实现轨迹对 TLA+ 的验证论文](https://arxiv.org/abs/2404.16075)支持以受约束模型检查处理 Java 部分观测 trace。
- [MongoDB 模型测试经验](https://www.vldb.org/pvldb/vol13/p1346-davis.pdf)用于约束抽象粒度、状态快照和模型生成测试边界。
